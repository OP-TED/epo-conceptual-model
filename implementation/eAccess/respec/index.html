This document describes the usage of the following main entities for a correct usage of the vocabulary:
| ESPD request | Information request | Information response | Invitation to tender | Procurement documents provision | Procurement documents request | Procurement question | Procurement question reply | Unsubscribe from procedure | Unsubscribe from procedure response |
