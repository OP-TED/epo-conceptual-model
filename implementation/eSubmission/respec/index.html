Main Entities

The main entities are those that form the core of the vocabulary. Properties of entities are listed in a tabular form.

Documentary evidence

Definition
An Evidence submitted by an Economic Operator to prove compliance with legal, technical or financial requirements, or inapplicability of exclusion grounds in a Procurement Procedure.
Subclass of
Evidence
Properties
This specification does not impose any additional requirements to properties for this entity.

ESPD

Definition
A self-declaration of an economic operator, stating that it does not fall under the Exclusion Grounds and that it meets the Selection Criteria for a specific procurement.

Definition
Information about the specific features or characteristics that qualify an economic operator to take part in a tendering process.
Subclass of
Context description
Properties
For this entity the following properties are defined: concerns organisation, has business classification description, provides organisation completed task description, provides organisation employee quantity, provides organisation financial capability.
Property Range Card Definition Usage Feedback
concerns organisation

Organization

 1 Relates to Organization.
has business classification description Plain literal 0..* Explanatory text about the size of the Business. Additional information: The values of this property may come from the recommended codelist: http://publications.europa.eu/resource/authority/economic-operator-size
provides organisation completed task description Plain literal 0..1 Text describing the works, supplies or services executed, delivered or performed in a procurement project that can be used as an evidence for the classification of the Organization.

Monetary value

 0..1 A monetary amount representing the financial capability of the Organization. Additional information: Used to represent the general Turnover of the Organization (for statistical purposes).
