Main Entities

The main entities are those that form the core of the vocabulary. Properties of entities are listed in a tabular form.

Contract amendment

Definition
A change to an existing Contract that is agreed by the contracting parties.
Subclass of
Contract
Properties
For this entity the following properties are defined: amends contract, updates contract value.
Property Range Card Definition Usage Feedback

Contract modification information

Definition
Information about a Contract Amendment.
Subclass of
Context description
Properties
For this entity the following properties are defined: concerns contract amendment, has modification description, has modification justification, has modification reason description, relates to E form section identifier.
Property Range Card Definition Usage Feedback
concerns contract amendment Contract amendment 1 Relates to Contract Amendment.
has modification description Plain literal 0..1 An explanatory text about this context.

Concept
