The main entities are those that form the core of the vocabulary. Properties of entities are listed in a tabular form.

Evaluation board

Definition
Committee set up to evaluate the Tenders submitted. Additional Information: The committee may be a regular board or a jury.
Properties
For this entity the following properties are defined: has evaluator, has jury member, is appointed by, is assigned for evaluation of, requests clarification, writes evaluation report.

Evaluation criterion

Definition
A Criterion used by the Buyer to assess and compare Tenders in order to determine which Offer best meets the objectives of the Procurement Procedure.
Properties
For this entity the following properties are defined: evaluates procurement criterion, fulfills procurement criterion, has evaluation justification, has score point.
