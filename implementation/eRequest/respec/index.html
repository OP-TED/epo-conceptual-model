Main Entities

The main entities are those that form the core of the vocabulary. Properties of entities are listed in a tabular form.

Request for offer

Definition
A Document sent by the Buyer to the Economic Operator, requesting the submission of a commercial proposal to supply goods, services, or works under specified conditions.
Subclass of
Document
Properties
For this entity the following properties are defined: comprises request for offer line, has destination country code, has submission due date, refers to catalogue, refers to contract, specifies buyer, specifies contractor, specifies delivery information, specifies offer currency, specifies offer validity period, specifies originator.
